## 📖 เกี่ยวกับ Repository

Repository นี้รวบรวม **Custom Skills** สำหรับ AI Coding Assistant โดยเฉพาะ **Claude Code** เพื่อช่วยเพิ่มความสามารถเฉพาะทางให้กับ AI เช่น การคำนวณทางบัญชีและภาษี, การจัดการงานเฉพาะทาง และ Workflow อัตโนมัติต่างๆ

แต่ละ Skill จะบรรจุอยู่ในโฟลเดอร์ของตัวเอง พร้อมไฟล์ `SKILL.md` ที่มีคำแนะนำ กฎเกณฑ์ ตารางอ้างอิง และตัวอย่างการคำนวณที่ชัดเจน

## 💬 วิธีทดสอบการใช้งาน (Usage)

เมื่อติดตั้งเสร็จแล้ว สามารถเปิดใช้งาน **Claude Code** และพิมพ์สอบถามได้ทันที Claude จะเรียกใช้งาน Skill ที่เกี่ยวข้องโดยอัตโนมัติ เช่น:

**ตัวอย่างคำถามเกี่ยวกับค่าเสื่อมราคา:**
```text
> คำนวณค่าเสื่อมราคาคอมพิวเตอร์โน้ตบุ๊กราคา 30,000 บาท อายุการใช้งาน 3 ปี ซื้อต้นเดือนเมษายนให้หน่อย
```
```text
> บริษัทซื้อรถยนต์นั่งราคา 1,500,000 บาท ช่วยเปรียบเทียบการลงบัญชี TAS 16 กับการหักค่าเสื่อมทางภาษีสรรพากรให้หน่อย
```

**ตัวอย่างคำถามเกี่ยวกับกระทบยอด ภ.พ.30 / ภาษี:**
```text
> ช่วยทำกระดาษทำการกระทบยอด ภ.พ.30 12 เดือนกับงบกำไรขาดทุน รายได้รวม 16,988,000 บาท มีดอกเบี้ยรับและกำไรจากอัตราแลกเปลี่ยน
```
```text
> ยอดขายรวม VAT ได้รับมา 12,840,000 บาท ต้องถอดภาษีขายด้วยสูตรไหน และบันทึกบัญชีอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับเงินมัดจำ เงินประกัน และภาษีมูลค่าเพิ่ม:**
```text
> รับเงินมัดจำค่าจ้างทำของ 30% ต้องออกใบกำกับภาษีทันทีไหม หัก ณ ที่จ่ายเท่าไร และบันทึกบัญชีอย่างไร
```
```text
> เรียกเก็บเงินประกันสัญญาเช่าสำนักงาน 2 เดือน ต้องคิด VAT 7% ไหม และถ้าลูกค้ายกเลิกสัญญาแล้วริบมัดจำต้องเสียภาษีอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับบัตรคุมสินค้า (Stock Card):**
```text
> ช่วยทำตาราง Stock Card สินค้าราคาปรับขึ้น เปรียบเทียบต้นทุนขายและสินค้าคงเหลือปลายงวดระหว่างวิธี FIFO กับถัวเฉลี่ยเคลื่อนที่
```
```text
> สิ้นเดือนตรวจนับสต๊อกแล้วพบสินค้าขาดหายไป 2 ชิ้น ต้องลงบัตรคุมสินค้าอย่างไร และต้องเสียภาษีขายตาม ม.77/1(8)(จ) หรือไม่
```

**ตัวอย่างคำถามเกี่ยวกับเจ้าหนี้การค้า (AP):**
```text
> ซื้อสินค้า 100,000 บาท ได้เทอม 2/10 Net 30 หากจ่ายใน 10 วันเพื่อรับส่วนลดเงินสด 2% ต้องลงบัญชีและปรับภาษีซื้ออย่างไร
```
```text
> ได้รับบิลค่าบริการแต่ยังไม่ได้จ่ายเงิน ต้องบันทึกภาษีซื้อยังไม่ถึงกำหนดอย่างไร และเมื่อจ่ายเงินต้องหัก WHT 3% อย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับรายการปรับปรุงบัญชี (Adjusting Entries):**
```text
> ส่งมอบงานที่ปรึกษาปลายเดือนธันวาคมแต่วางบิลมกราคมปีหน้า ต้องปรับปรุงรายได้ค้างรับอย่างไร และกลับรายการต้นงวดทำอย่างไร
```
```text
> รับเงินค่าบริการ SaaS รายปีล่วงหน้า 120,000 บาท ผ่านไป 2 เดือน สิ้นปีต้องปรับปรุงรับรู้รายได้และหนี้สินอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับการกระทบยอดธนาคาร (Bank Reconciliation):**
```text
> ช่วยทำงบพิสูจน์ยอดเงินฝากธนาคารวิธีหายอดที่ถูกต้อง มียอด Statement 408,500 บาท มีเงินฝากระหว่างทาง เช็คค้างจ่าย และค่าธรรมเนียม
```

**ตัวอย่างคำถามเกี่ยวกับการบริหารสินค้าคงคลัง (Inventory Management):**
```text
> สินค้ามียอดใช้ปีละ 1,200 ชิ้น ต้นทุนสั่งซื้อครั้งละ 500 บาท ค่าเก็บรักษา 10 บาท/ชิ้น/ปี จงคำนวณ EOQ, Safety Stock และ ROP
```

**ตัวอย่างคำถามเกี่ยวกับการบริหารสินทรัพย์ถาวร (Fixed Asset Management):**
```text
> บริษัทเป็น SME ซื้อเครื่องจักรผลิต 1,000,000 บาท จะหักค่าเสื่อมราคาเบื้องต้น 40% ตาม พ.ร.ฎ. 395 ได้อย่างไร และช่วยประหยัดภาษีเท่าไร
```

**ตัวอย่างคำถามเกี่ยวกับบัญชีแยกประเภท (General Ledger):**
```text
> ซื้อสินค้าเงินเชื่อและขายสินค้าเงินเชื่อ ต้องผ่านรายการไปยังบัญชีแยกประเภททั่วไป (GL) และแยกประเภทย่อยอย่างไร พร้อมยกยอดออกงบทดลอง
```

**ตัวอย่างคำถามเกี่ยวกับสมุดบัญชีตามกฎหมาย (Books of Accounts):**
```text
> บริษัทเปิดใหม่ต้องมีสมุดบัญชีกี่เล่มตาม พ.ร.บ.การบัญชี พ.ศ. 2543 และการซื้อสินค้าเงินสดต้องลงสมุดรายวันซื้อหรือสมุดรายวันจ่ายเงิน
```

**ตัวอย่างคำถามเกี่ยวกับใบลดหนี้ (Credit Note):**
```text
> ลูกค้าคืนสินค้าชำรุด 40,000 บาท ต้องออกใบลดหนี้ตามคำสั่ง ป.80/2542 อย่างไร และกระทบต่อแบบ ภ.พ.30 ฝั่งผู้ซื้อผู้ขายอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับใบสำคัญรับเงิน (Receipt Voucher):**
```text
> จ้างช่างแอร์บุคคลธรรมดา 6,000 บาท ไม่มีใบเสร็จ ต้องทำใบสำคัญรับเงินและแนบหลักฐานอะไรเพื่อไม่ให้เป็นรายจ่ายต้องห้าม ม.65 ตรี (18)
```

**ตัวอย่างคำถามเกี่ยวกับบัญชีรายรับรายจ่ายร้านค้า (Shop Income-Expense):**
```text
> เปิดร้านขายของชำบุคคลธรรมดา มีรายได้ ม.40(8) ต้องทำรายงานเงินสดรับ-จ่ายตามประกาศฉบับที่ 161 อย่างไร และช่วยประหยัดภาษีเมื่อเทียบกับหักเหมา 60% อย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับกลยุทธ์การตรวจนับสินค้าคงเหลือ (Inventory Counting Strategies):**
```text
> บริษัทมีสินค้าพันกว่ารายการ ควรเลือกตรวจนับแบบ Physical Count สิ้นปี หรือ Cycle Count ดี และถ้าตรวจนับพบสินค้าขาดหายไป ต้องคิดภาษีขายตาม ม.77/1(8)(ค) และปรับปรุงบัญชีอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับการทำบัญชีธุรกิจและวางระบบ SME (How to do Accounting for Business):**
```text
> เพิ่งจดทะเบียนบริษัทจำกัดแต่ยังไม่มีรายได้ ต้องทำบัญชีและยื่นภาษีอะไรบ้าง และถ้ากรรมการโอนเงินส่วนตัวจ่ายค่าของแทนบริษัท จะบันทึกอย่างไรไม่ให้เสี่ยงดอกเบี้ย ม.65 ทวิ (4)
```

**ตัวอย่างคำถามเกี่ยวกับเงินสมทบกองทุนประกันสังคม (Social Security Contributions):**
```text
> คำนวณเงินสมทบประกันสังคม ม.33 สำหรับพนักงานเงินเดือน 12,000 บาท และ 45,000 บาท พร้อมค่าล่วงเวลา ต้องหักและนำส่งเท่าไร ยื่น e-Service ได้ถึงวันไหน และบันทึกบัญชีอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับการปรับเงินเดือนพนักงาน (Employee Salary Adjustment):**
```text
> บริษัทขาดทุนอยากขอลดเงินเดือนพนักงาน 15% ทำได้ตามกฎหมายแรงงานหรือไม่ และถ้าจะปรับฐานเงินเดือนขึ้นตาม Merit Matrix ต้องคำนวณและปรับภาษี ภ.ง.ด.1 ใหม่อย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับสลิปเงินเดือน (Salary Slip Information):**
```text
> สลิปเงินเดือนพนักงานต้องมีองค์ประกอบสำคัญอะไรบ้างตามกฎหมายแรงงาน และต้องทำ 3-Way Reconciliation กระทบยอด Gross Pay กับ ภ.ง.ด.1 และบัญชีแยกประเภทอย่างไร
```

**ตัวอย่างคำถามเกี่ยวกับหนังสือรับรองเงินเดือนและรายได้ (Income Certificate):**
```text
> พนักงานขอหนังสือรับรองเงินเดือนไปยื่นกู้ซื้อบ้าน ต้องระบุโอทีและคอมมิชชันในฐานเงินเดือนหรือไม่ และถ้ากรรมการออกหนังสือรับรองยอดเงินเดือนสูงกว่าจริงจะมีความผิดทางอาญาอย่างไร
```

## ➕ การเพิ่ม Skill ใหม่ (How to Add New Skill)

หากต้องการสร้างหรือเพิ่ม Skill ใหม่ ให้ทำตามโครงสร้างมาตรฐานดังนี้:

1. สร้างโฟลเดอร์ใหม่ตามชื่อ Skill เช่น `my-new-skill/`
2. สร้างไฟล์ `SKILL.md` ภายในโฟลเดอร์ โดยมี Frontmatter ด้านบนสุด:

```markdown
---
name: my-new-skill
description: อธิบายว่า Skill นี้ใช้ทำอะไร และควรเรียกใช้เมื่อใด
---

# My New Skill Title

## Overview
คำอธิบายภาพรวมและบริบท

## Instructions & Rules
กฎเกณฑ์และขั้นตอนการทำงาน
```

3. Commit และ Push ขึ้น Repository ได้ทันที!
