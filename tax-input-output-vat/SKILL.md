# คู่มือและมาตรฐานการจัดการภาษีซื้อและภาษีขาย (Thai Input & Output VAT Guide)

แนวทางปฏิบัติและหลักเกณฑ์ทางกฎหมายตามประมวลรัษฎากรสำหรับการบริหารจัดการภาษีซื้อ (Input VAT) และภาษีขาย (Output VAT) การคำนวณภาษีมูลค่าเพิ่มสุทธิประจำเดือน การบันทึกบัญชีโอนปิดบัญชีภาษีสิ้นงวด การตรวจสอบภาษีซื้อต้องห้าม และการยื่นแบบ ภ.พ.30

---

## 1. นิยามและการจัดหมวดหมู่บัญชีตามมาตรฐานการบัญชีไทย

| รายการ | ภาษีซื้อ (Input VAT) | ภาษีขาย (Output VAT) |
| :--- | :--- | :--- |
| **ความหมาย** | ภาษีมูลค่าเพิ่ม 7% ที่กิจการจ่ายให้ผู้ขายสินค้า/บริการที่จดทะเบียน VAT | ภาษีมูลค่าเพิ่ม 7% ที่กิจการเรียกเก็บจากลูกค้าเมื่อขายสินค้าหรือให้บริการ |
| **สถานะทางกฎหมาย** | เป็นสิทธิเรียกร้องที่กิจการมีต่อกรมสรรพากร เพื่อนำไปหักออกจากภาษีขาย | เป็นเงินของรัฐบาลที่กิจการเรียกเก็บแทนกรมสรรพากร มิใช่รายได้ของกิจการ |
| **หมวดบัญชี** | **หมวด 1: สินทรัพย์หมุนเวียน (Current Assets)** | **หมวด 2: หนี้สินหมุนเวียน (Current Liabilities)** |
| **รหัสบัญชีมาตรฐาน** | `115401` ภาษีซื้อ | `215301` ภาษีขาย |
| **เอกสารหลักฐาน** | ใบกำกับภาษีเต็มรูป (ม.86/4) หรือใบเสร็จ ภ.พ.36 | สำเนาใบกำกับภาษีเต็มรูป หรือใบกำกับภาษีอย่างย่อ |

---

## 2. สูตรการคำนวณและดุลภาษีมูลค่าเพิ่มประจำเดือน

$$\text{ภาษีมูลค่าเพิ่มสุทธิที่ต้องนำส่ง (หรือขอคืน)} = \text{ภาษีขายในงวด} - \text{ภาษีซื้อที่ขอหักได้ในงวด}$$

- **ผลลัพธ์เป็นบวก ($\text{ภาษีขาย} > \text{ภาษีซื้อ}$):** กิจการมีหน้าที่ต้องชำระภาษีส่วนต่างให้แก่กรมสรรพากร
- **ผลลัพธ์เป็นลบ ($\text{ภาษีซื้อ} > \text{ภาษีขาย}$):** กิจการมีสิทธิเลือกได้ 2 ทาง:
  1. ขอคืนเป็นเงินสด (Cash Refund) หรือโอนเข้าบัญชีธนาคาร
  2. ยกยอดไปเป็น **"เครดิตภาษี" (Tax Credit)** เพื่อหักกลบกับภาษีขายในเดือนภาษีถัดไป

---

## 3. การบันทึกบัญชีโอนปิดภาษีซื้อและภาษีขายสิ้นเดือน (Month-End VAT Settlement)

ทุกวันสิ้นเดือน กิจการต้องโอนปิดยอดบัญชีภาษีซื้อและภาษีขาย เพื่อสรุปยอดดุลสุทธิทางบัญชี:

### 3.1 กรณีที่ 1: ภาษีขายมากกว่าภาษีซื้อ (ต้องนำส่งภาษี)
*ตัวอย่าง:* เดือนมกราคม บริษัทฯ มีภาษีขาย 35,000 บาท และภาษีซื้อ 21,000 บาท (ภาษีที่ต้องนำส่ง = 14,000 บาท)

**1. สิ้นเดือนบันทึกโอนปิดภาษีซื้อ-ภาษีขาย (ณ วันที่ 31 มกราคม):**
```
เดบิต  ภาษีขาย (215301)                             35,000.00
    เครดิต  ภาษีซื้อ (115401)                                21,000.00
    เครดิต  เจ้าหนี้กรมสรรพากร (215302)                       14,000.00
(บันทึกโอนปิดบัญชีภาษีซื้อภาษีขายเพื่อรับรู้ยอดหนี้สินที่ต้องนำส่ง ภ.พ.30)
```

**2. วันที่นำส่งภาษีพร้อมแบบ ภ.พ.30 (ภายในวันที่ 15 หรือ 23 กุมภาพันธ์):**
```
เดบิต  เจ้าหนี้กรมสรรพากร (215302)                   14,000.00
    เครดิต  เงินฝากธนาคาร / เงินสด                            14,000.00
(บันทึกการชำระภาษีมูลค่าเพิ่มให้กรมสรรพากรตามแบบ ภ.พ.30)
```

---

### 3.2 กรณีที่ 2: ภาษีซื้อมากกว่าภาษีขาย (ขอคืนภาษีหรือยกยอดเครดิต)
*ตัวอย่าง:* เดือนกุมภาพันธ์ บริษัทฯ มีภาษีขาย 14,000 บาท และภาษีซื้อ 28,000 บาท (ภาษีซื้อเกิน = 14,000 บาท)

**1. สิ้นเดือนบันทึกโอนปิดภาษีซื้อ-ภาษีขาย (ณ วันที่ 28/29 กุมภาพันธ์):**
*ทางเลือก ก: ยกยอดเป็นเครดิตภาษีเดือนถัดไป (แนะนำสำหรับธุรกิจทั่วไป)*
```
เดบิต  ภาษีขาย (215301)                             14,000.00
เดบิต  เครดิต ภ.พ.30 ยกไป (115451)                  14,000.00
    เครดิต  ภาษีซื้อ (115401)                                28,000.00
(บันทึกโอนปิดภาษีซื้อภาษีขายและตั้งยอดเครดิตภาษียกไปหักเดือนถัดไป)
```

*ทางเลือก ข: ขอคืนเป็นเงินสดจากกรมสรรพากร*
```
เดบิต  ภาษีขาย (215301)                             14,000.00
เดบิต  ลูกหนี้สรรพากร - ขอคืน VAT (115405)           14,000.00
    เครดิต  ภาษีซื้อ (115401)                                28,000.00
(บันทึกโอนปิดภาษีซื้อภาษีขายและตั้งยอดลูกหนี้สรรพากรขอคืนเงินสด)
```

**2. เมื่อนำเครดิตไปหักในเดือนถัดไป (สมมติเดือนมีนาคมมีภาษีขายสุทธิ):**
```
เดบิต  ภาษีขาย (215301)                             ...
    เครดิต  เครดิต ภ.พ.30 ยกไป (115451)                      14,000.00
    เครดิต  เจ้าหนี้กรมสรรพากร (215302)                       ส่วนต่าง (ถ้ามี)
```

## 4. ภาษีซื้อต้องห้ามตามประมวลรัษฎากร (Non-Deductible Input Tax)

ภาษีซื้อต้องห้าม คือภาษีมูลค่าเพิ่มที่กิจการจ่ายจริง แต่กฎหมาย **ห้ามมิให้นำไปหักออกจากภาษีขาย หรือห้ามขอคืน** ตามมาตรา 82/5 และประกาศอธิบดีกรมสรรพากรฯ:

| ประเภทภาษีซื้อต้องห้าม | ข้อกฎหมายอ้างอิง | การปฏิบัติทางภาษีเงินได้นิติบุคคล |
| :--- | :--- | :--- |
| **1. ไม่มีใบกำกับภาษี หรือไม่อาจแสดงใบกำกับภาษีได้** | ม. 82/5(1) | **ห้ามหักเป็นค่าใช้จ่ายเด็ดขาด** (ม.65 ตรี (18) รายจ่ายที่พิสูจน์ผู้รับไม่ได้) |
| **2. ใบกำกับภาษีมีข้อความไม่สมบูรณ์หรือไม่ถูกต้อง** เช่น ชื่อผิด, เลข 13 หลักผิด, เลือนราง | ม. 82/5(2) | นำไปหักเป็นค่าใช้จ่ายทางภาษีได้ หากพิสูจน์ได้ว่าเป็นรายจ่ายของกิจการจริง |
| **3. ภาษีซื้อที่ไม่เกี่ยวข้องโดยตรงกับการประกอบกิจการ** เช่น ของใช้ส่วนตัวกรรมการ | ม. 82/5(3) | **ห้ามหักเป็นค่าใช้จ่าย** (ม.65 ตรี (13) รายจ่ายส่วนตัวหรือเสน่หา) |
| **4. ภาษีซื้อจากค่ารับรอง** เช่น ค่าอาหารเลี้ยงรับรองลูกค้า, ของขวัญ | ม. 82/5(4) | **นำไปรวมเป็นต้นทุนค่ารับรอง** และหักภาษีนิติบุคคลได้ตามเพดานกฎกระทรวง ฉบับที่ 186 |
| **5. ภาษีซื้อจากรถยนต์นั่งและรถโดยสารที่มีที่นั่งไม่เกิน 10 คน** (รวมค่าซื้อ เช่า ซ่อม และน้ำมัน) | ม. 82/5(6) | **นำไปรวมเป็นต้นทุนของทรัพย์สินหรือค่าใช้จ่าย** และหักค่าเสื่อมราคาทางภาษีได้ตามเกณฑ์ |
| **6. ภาษีซื้อตามใบกำกับภาษีอย่างย่อ** | ม. 86/6 | **นำไปรวมเป็นค่าใช้จ่ายทางบัญชีและภาษีได้** หากมีบิลระบุรายการชัดเจนเพื่อกิจการ |

> [!CAUTION] การบันทึกบัญชีภาษีซื้อต้องห้าม
> สำหรับภาษีซื้อที่ไม่สามารถนำมาหักใน ภ.พ.30 ได้ แต่เป็นค่าใช้จ่ายของกิจการจริง (เช่น ค่ารับรอง หรือรถยนต์นั่ง) **ให้บันทึกยอด VAT รวมเข้าเป็นต้นทุนของค่าใช้จ่ายหรือสินทรัพย์นั้นๆ ทันที** ห้ามบันทึกเข้าบัญชีภาษีซื้อ (115401) เด็ดขาด

## 5. กำหนดเวลาและเงื่อนไขการยื่นแบบ ภ.พ.30

1. **กำหนดยื่นแบบกระดาษ:** ภายในวันที่ 15 ของเดือนถัดไป ณ สำนักงานสรรพากรพื้นที่สาขา
2. **กำหนดยื่นแบบผ่านระบบ e-Filing:** ได้รับสิทธิขยายเวลาเพิ่มอีก 8 วัน เป็น **ภายในวันที่ 23 ของเดือนถัดไป**
3. **หน้าที่ยื่นแบบเปล่า (Nil Return):** แม้ในเดือนภาษีนั้น กิจการจะไม่มีการซื้อสินค้า/บริการ และไม่มีการขายสินค้า/บริการเลย กิจการ **ยังมีหน้าที่ต้องยื่นแบบ ภ.พ.30 โดยระบุยอดเป็น 0 บาท** มิฉะนั้นจะต้องระวางโทษปรับตามกฎหมาย

## 6. รายการตรวจสอบความถูกต้องประจำเดือน (Monthly VAT Checklist)

- [ ] กระทบยอดรายงานภาษีขายกับบัญชีรายได้ และกระทบยอดรายงานภาษีซื้อกับสมุดรายวันซื้อ
- [ ] ตรวจสอบว่าใบกำกับภาษีซื้อทุกฉบับมีข้อความครบถ้วน 8 รายการตามมาตรา 86/4
- [ ] คัดแยกใบกำกับภาษีที่เป็น "ภาษีซื้อต้องห้าม" ออกจากรายงานภาษีซื้อ และบันทึกเป็นต้นทุนค่าใช้จ่าย
- [ ] จัดทำบันทึกบัญชีโอนปิดภาษีซื้อ-ภาษีขายในสมุดรายวันทั่วไป (JV) ณ วันสิ้นเดือน
- [ ] ยื่นแบบ ภ.พ.30 และชำระภาษีภายในวันที่ 15 (กระดาษ) หรือ วันที่ 23 (ออนไลน์)
- [ ] จัดเก็บใบกำกับภาษีและรายงานภาษีซื้อ-ภาษีขายไว้อย่างปลอดภัยไม่น้อยกว่า 5-7 ปี ตามมาตรา 87/3
